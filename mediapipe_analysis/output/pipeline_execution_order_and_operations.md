## Detailed Call Graph

### 1. Palm Detection Pipeline (PalmDetectionCpu)

**Input**: ImageFrame (input image)  
**Output**: std::vector<Detection> (palm detections)

#### Calculator Execution Flow:

1. **ImageToTensorCalculator**
   - **Purpose**: Converts input image to 192x192 tensor
   - **Input**: ImageFrame
   - **Output**: Tensor (normalized 0.0-1.0), letterbox padding info
   - **Key Operations**: 
     - Resize image to 192x192 with aspect ratio preservation
     - Normalize pixel values to [0.0, 1.0]
     - Apply zero padding for letterboxing

2. **TfLiteCustomOpResolverCalculator**
   - **Purpose**: Creates TensorFlow Lite custom operation resolver
   - **Output**: OP_RESOLVER side packet
   - **Key Operations**: 
     - Registers custom ops needed by palm detection model

3. **PalmDetectionModelLoader**
   - **Purpose**: Loads appropriate TFLite model based on complexity
   - **Input**: MODEL_COMPLEXITY side packet
   - **Output**: MODEL side packet
   - **Key Operations**: 
     - Selects between palm_detection_lite.tflite or palm_detection_full.tflite
     - Loads TFLite model into memory

4. **InferenceCalculator**
   - **Purpose**: Runs TensorFlow Lite inference
   - **Input**: Tensor (image), MODEL, OP_RESOLVER
   - **Output**: Tensor vector (raw model outputs)
   - **Key Operations**: 
     - Executes palm detection neural network
     - Uses XNNPACK delegate for CPU optimization

5. **SsdAnchorsCalculator**
   - **Purpose**: Generates SSD anchor boxes
   - **Output**: Anchors side packet
   - **Key Operations**: 
     - Creates 2016 anchor boxes across 4 scales
     - Anchors distributed across feature map locations

6. **TensorsToDetectionsCalculator**
   - **Purpose**: Converts raw tensor outputs to Detection objects
   - **Input**: Tensor vector, Anchors
   - **Output**: std::vector<Detection> (unfiltered)
   - **Key Operations**: 
     - Decodes bounding boxes from tensor outputs
     - Extracts 7 keypoints per detection
     - Applies sigmoid to confidence scores
     - Filters by minimum score threshold (0.5)

7. **NonMaxSuppressionCalculator**
   - **Purpose**: Removes overlapping detections
   - **Input**: std::vector<Detection> (unfiltered)
   - **Output**: std::vector<Detection> (filtered)
   - **Key Operations**: 
     - Applies weighted NMS algorithm
     - IOU threshold: 0.3
     - Removes redundant detections

8. **DetectionLetterboxRemovalCalculator**
   - **Purpose**: Adjusts detection coordinates for letterboxing
   - **Input**: std::vector<Detection>, letterbox padding
   - **Output**: std::vector<Detection> (final)
   - **Key Operations**: 
     - Converts coordinates from letterboxed space to original image space

### 2. Hand Landmark Detection Pipeline (HandLandmarkCpu)

**Input**: ImageFrame, NormalizedRect (hand ROI)  
**Output**: NormalizedLandmarkList, LandmarkList, ClassificationList

#### Calculator Execution Flow:

1. **ImageToTensorCalculator**
   - **Purpose**: Crops and resizes hand region to 224x224 tensor
   - **Input**: ImageFrame, NormalizedRect (ROI)
   - **Output**: Tensor (224x224x3), letterbox padding
   - **Key Operations**: 
     - Crop image using ROI coordinates
     - Resize to 224x224 with aspect ratio preservation
     - Normalize to [0.0, 1.0]

2. **HandLandmarkModelLoader**
   - **Purpose**: Loads hand landmark TFLite model
   - **Input**: MODEL_COMPLEXITY side packet
   - **Output**: MODEL side packet
   - **Key Operations**: 
     - Selects between hand_landmark_lite.tflite or hand_landmark_full.tflite

3. **InferenceCalculator**
   - **Purpose**: Runs hand landmark neural network
   - **Input**: Tensor (cropped hand), MODEL
   - **Output**: Tensor vector (4 output tensors)
   - **Key Operations**: 
     - Executes hand landmark detection network
     - Outputs: landmarks, hand_flag, handedness, world_landmarks

4. **SplitTensorVectorCalculator**
   - **Purpose**: Splits model outputs into separate tensors
   - **Input**: Tensor vector (4 tensors)
   - **Output**: 4 separate tensor streams
   - **Key Operations**: 
     - landmark_tensors (0-1): 2D landmarks
     - hand_flag_tensor (1-2): Hand presence confidence
     - handedness_tensor (2-3): Left/right classification
     - world_landmark_tensor (3-4): 3D world landmarks

5. **TensorsToFloatsCalculator**
   - **Purpose**: Converts hand flag tensor to confidence score
   - **Input**: hand_flag_tensor
   - **Output**: FLOAT (hand presence score)

6. **ThresholdingCalculator**
   - **Purpose**: Determines hand presence
   - **Input**: FLOAT (hand presence score)
   - **Output**: FLAG (hand_presence boolean)
   - **Key Operations**: 
     - Applies threshold of 0.5
     - Gates downstream processing

7. **GateCalculator**
   - **Purpose**: Conditionally passes data based on hand presence
   - **Input**: Various tensors + hand_presence flag
   - **Output**: Gated tensor streams
   - **Key Operations**: 
     - Prevents processing if no hand detected
     - Applied to handedness, landmarks, and world landmarks

8. **TensorsToClassificationCalculator**
   - **Purpose**: Converts handedness tensor to classification
   - **Input**: handedness_tensor
   - **Output**: ClassificationList (left/right hand)
   - **Key Operations**: 
     - Binary classification using handedness.txt labels
     - Top-1 classification result

9. **TensorsToLandmarksCalculator**
   - **Purpose**: Converts landmark tensor to 2D landmark list
   - **Input**: landmark_tensors
   - **Output**: NormalizedLandmarkList (21 landmarks)
   - **Key Operations**: 
     - Extracts 21 hand landmarks
     - Normalizes coordinates to input image size (224x224)
     - Applies Z-coordinate normalization (0.4 factor)

10. **LandmarkLetterboxRemovalCalculator**
   - **Purpose**: Adjusts landmarks for letterboxing removal
   - **Input**: landmarks, letterbox_padding
   - **Output**: scaled_landmarks
   - **Key Operations**: 
     - Converts from letterboxed coordinates to cropped hand coordinates

11. **LandmarkProjectionCalculator**
   - **Purpose**: Projects landmarks from cropped hand to full image
   - **Input**: scaled_landmarks, hand_rect
   - **Output**: hand_landmarks (final 2D landmarks)
   - **Key Operations**: 
     - Applies inverse transformation of hand ROI cropping
     - Projects landmarks to original image coordinates

12. **TensorsToLandmarksCalculator**
   - **Purpose**: Converts world landmark tensor to 3D landmark list
   - **Input**: world_landmark_tensor
   - **Output**: unprojected_world_landmarks
   - **Key Operations**: 
     - Extracts 21 3D landmarks in meters
     - World coordinates relative to hand center

13. **WorldLandmarkProjectionCalculator**
   - **Purpose**: Projects 3D landmarks to world coordinate system
   - **Input**: unprojected_world_landmarks, hand_rect
   - **Output**: hand_world_landmarks (final 3D landmarks)
   - **Key Operations**: 
     - Maintains metric scale in meters
     - Origin at hand bounding box center

### 3. Main Pipeline Orchestration (HandLandmarkTrackingCpu)

#### Key Control Flow Calculators:

1. **GateCalculator**
   - Controls whether to use previous frame landmarks for tracking
   - use previous landmarks

2. **NormalizedRectVectorHasMinSizeCalculator**
   - Checks if enough hands detected in previous frame

3. **GateCalculator**
   - Decides whether to run palm detection or use previous tracking
   - trigger palm detection

4. **BeginLoopDetectionCalculator / EndLoopNormalizedRectCalculator**
   - Processes multiple palm detections in parallel

5. **AssociationNormRectCalculator**
   - Associates current detections with previous frame trackings
   - Uses similarity threshold of 0.5

6. **BeginLoopNormalizedRectCalculator / EndLoop calculators**
   - Processes multiple hand regions in parallel
   - Collects results into vectors

7. **PreviousLoopbackCalculator**
   - Implements temporal feedback loop
   - Caches hand ROIs for next frame
