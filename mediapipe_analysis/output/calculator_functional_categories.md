## Execution Flow Description

The MediaPipe hand inference pipeline follows this general flow:

1. **Image Input Processing** - Input image is processed to extract properties
2. **Palm Detection** - Detect palms in the image using ML model
3. **ROI Extraction** - Convert palm detections to regions of interest
4. **Hand Landmark Detection** - Run landmark detection on hand ROIs
5. **Coordinate Transformation** - Transform landmarks between coordinate systems
6. **Tracking Preparation** - Generate ROIs for next frame tracking
