# MediaPipe Hand Inference Analysis

This directory contains code analysing the mediapipe hand tracking pipeline from the current codebase's code revision of mediapipe, ported from https://github.com/nui-ai/mediapipe-liberation/ where this kind of work originally took place. 
<br>
The output path of it contains the outputs of the last run of that code, which is included in the repository as we don't aim to modify
the mediapipe pipeline in ways making that run obsolete, but you can always re-run the analysis code again.

## Overview

MediaPipe uses a complex bazel-built computation graph architecture that makes it difficult to understand and modify the actual inference flow. This analysis provides tools to:

1. **Map the complete C++ call graph** of MediaPipe's hand inference pipeline
2. **Extract neural network models** and understand their preprocessing/postprocessing
3. **Generate comprehensive documentation** with clear relationships between components

**Note**: For the standalone Python implementation that bypasses MediaPipe's framework, see the [`python_implementation/`](../python_implementation/) directory.

## Architecture

### Pipeline Flow
1. **Image Input** → Image preprocessing (resize, normalize, letterbox)
2. **Palm Detection** → TFLite inference → Anchor decoding → NMS filtering
3. **ROI Extraction** → Extract hand regions from palm detections
4. **Hand Landmarks** → TFLite inference → Coordinate transformation
5. **Output Generation** → Format results matching MediaPipe API

### Key Components

#### StandaloneHandInference
Main pipeline class that orchestrates the complete inference flow.

#### PalmDetectionModel
- Loads `palm_detection_full.tflite`
- Implements SSD anchor generation
- Performs detection postprocessing with NMS

#### HandLandmarkModel  
- Loads `hand_landmark_full.tflite`
- Extracts ROIs from palm detections
- Transforms landmarks to normalized coordinates

#### MediaPipePreprocessor
- Image resizing with aspect ratio preservation
- Letterboxing and padding
- Normalization to model input range

#### Processing Logic Extraction
- `SsdAnchorsGenerator` - Generates detection anchors
- `TensorsToDetectionsProcessor` - Decodes detection outputs
- `TensorsToLandmarksProcessor` - Processes landmark predictions
- `CoordinateTransformer` - Handles coordinate transformations

## Model Requirements

The pipeline requires two TensorFlow Lite models:
- **`tflite/palm_detection_full.tflite`** (2.3MB) - Palm detection model
- **`tflite/hand_landmark_full.tflite`** (5.5MB) - Hand landmark model

These models are the same ones used by MediaPipe's hand inference pipeline.

## Execution Flow

The pipeline follows this high-level execution flow:

1. **Image Input** → `ImagePropertiesCalculator`
2. **Palm Detection** → `PalmDetectionCpu` subgraph
3. **Detection Filtering** → `ClipDetectionVectorSizeCalculator`
4. **ROI Generation** → `PalmDetectionDetectionToRoi`
5. **Hand Landmark Detection** → `HandLandmarkCpu` subgraph
6. **Landmark Processing** → Various transformation calculators
7. **Tracking ROI Generation** → `HandLandmarksToRectCalculator`

## MediaPipe Version

This analysis is specific to **MediaPipe v0.10.13**, which is the version used by the nui-ai/core repository. The analysis downloads and analyzes the exact commit tagged as v0.10.13 from the Google MediaPipe repository.
